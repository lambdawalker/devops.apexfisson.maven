# Guided setup UI and encrypted token cache

User requests a friendlier Cloudflare question, steps/status/progress in the terminal (Textual suggested), and a save-tokens script using passphrase-protected GPG. Setup automatically detects the encrypted file, retries decryption at most three times, then resumes normal token prompts. Windows/Linux and uv remain supported; existing migration/preflight/preview gates remain.

Default setup uses Textual with a persistent ordered checklist, active-stage elapsed time/activity, overall completed-step progress, safe scrollable output and masked prompts. A --plain mode preserves the basic terminal flow. An actual Pulumi browser/token login temporarily suspends the TUI and resumes afterward. Work runs in a worker; quitting requests cooperative cancellation, does not leave an unattended worker doing writes. At input prompts cancellation aborts promptly; during an external operation UI waits for its outcome then stops before the next step. Display final success/cancel/failure without falsely completing remaining steps or exposing exception locals.

Question: 'Is your domain's DNS managed by Cloudflare? yes/no [yes]'. Explain what yes means when an existing legacy stack is detected, preserving its resources. No answers exit safely with guidance; this wizard supports Cloudflare DNS, legacy GitHub-only configuration remains available. Preview and paid update confirmation are unchanged.

scripts/save_tokens.py collects GitHub, DigitalOcean, Cloudflare tokens with hidden input and a confirmed encryption passphrase. It writes only encrypted bytes atomically to .local/tokens.gpg (ignored), confirming overwrite. Optional --tokens-file overrides both scripts; encrypted data only, no plaintext/passphrase files, arguments or env variables. GPG symmetric AES256, pinentry-loopback/batch/no-symkey-cache. Decrypted data schema has a version and exact known string token keys; reject invalid/unexpected/oversized data. GPG diagnostics remain redacted. GPG is optional if there is no file or when normal prompts are used. Real GPG roundtrip and wrong-password tests use fake tokens and isolated GNUPGHOME.

Setup uses loaded tokens in-memory; never silently saves manual input. Missing file skips decryption. Existing file asks hidden passphrase up to three attempts; after a failed attempt ask whether to retry, with a clear manual-entry option. Third failure always falls back. Corrupt/unavailable files/GPG fall back with safe guidance. --saved-login explicitly keeps precedence for GitHub auth. Github-only mode uses saved GitHub/DO tokens if unlocked but does not require Cloudflare at runtime. Pulumi auth remains separate.
